WHAT IT FINDS

What can Findra actually find?

Names first. Then, if you ask, everything else. Names cost seconds to index, so they are on from the moment Findra starts. Reading inside files walks every drive and can run for hours, so it never begins on its own. You turn it on, one capability at a time, and each one is a separate download you can decline.

Everything Findra can install adds up to 3.7 GB, and that is the figure only if you take all of it. Take none and it still searches every name on the machine. On the first screen each row is priced at its own files, so the number never moves when you tick it and the four rows add up to that 3.7 GB; the line along the bottom is what your selection actually costs, and it is smaller whenever two capabilities share a file. Settings prices the same capabilities differently, and correctly for the question being asked there: what one more would add to what is already on the disk.
